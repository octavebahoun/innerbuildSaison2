Accessibilité

Synnova TOCLOE s'engage à rendre son site web accessible à tous. Cette page explique nos efforts d'accessibilité et notre conformité aux normes.

Notre Engagement

Nous croyons que le web doit être accessible à tous, indépendamment de leurs capacités physiques, sensorielles ou cognitives. Nous mettons en œuvre les bonnes pratiques d'accessibilité et nous nous conformons autant que possible aux directives WCAG 2.1 niveau AA.

Conformité WCAG 2.1

Notre site respecte les directives WCAG 2.1 (Web Content Accessibility Guidelines) publiées par le W3C :

✓
Niveau A — Objectif prioritaire atteint
✓
Niveau AA — Conformité visée et largement respectée

Fonctionnalités d'Accessibilité

Navigation au Clavier

Le site est entièrement navigable au clavier. Utilisez Tab, Shift+Tab, Enter et Escape.

Focus Trap Menu Mobile

La navigation mobile empêche le focus de sortir du menu pour une meilleure accessibilité clavier.

Contraste Élevé

Texte blanc sur fond sombre offre un contraste WCAG AAA (18.5:1).

Alt Text sur Images

Toutes les images ont des descriptions textuelles pour les lecteurs d'écran.

ARIA Live Regions

Les messages de formulaire sont annoncés dynamiquement aux lecteurs d'écran.

Sémantique HTML+

Structure sémantique correcte avec headers, nav, main, footer et landmarks ARIA.

Lecteurs d'Écran

Ce site a été testé avec les lecteurs d'écran suivants et fonctionne correctement :

  • → NVDA (Windows) — Gratuit, open-source
  • → JAWS (Windows) — Utilisé par les professionnels
  • → VoiceOver (macOS, iOS) — Intégré à Apple
  • → TalkBack (Android) — Lecteur d'écran Android

Limitations Connues

Nous travaillons continuellement à améliorer l'accessibilité. Certaines zones peuvent présenter des défis :

  • • Les animations GSAP parallax peuvent être perturbantes pour utilisateurs vestibulaires (mais respectent prefers-reduced-motion)
  • • Les images du portfolio décoratives ne ont pas de descriptions détaillées

Signaler un Problème

Si vous rencontrez un problème d'accessibilité sur ce site, veuillez nous le signaler :

📧 Nous Contacter

Décrivez le problème, le navigateur/appareil utilisé, et le lecteur d'écran si applicable.

Standards & Outils

Ce site respecte les standards suivants et utilise ces outils de validation :

✓ WCAG 2.1 AA — Web Content Accessibility Guidelines niveau AA
✓ HTML5 Semantic — Structure HTML5 correcte et sémantique
✓ ARIA 1.2 — Accessible Rich Internet Applications
✓ WAVE — WebAIM Evaluation Tool pour validation
✓ Lighthouse — Google Lighthouse Accessibility Audit
